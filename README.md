# Insertrix

A tetris clone, built with HTML5/JavaScript.

## Build

This is plain JavaScript (not even minified), no building needed.

## Run

Just open `index.html` in any web browser.


## Post series

This is a sample created through a series of posts in [dev.to](http://dev.to/) (in Spanish), which can be found in the [series dev.to webpage about Insertrix](https://dev.to/baltasarq/series/27594).
