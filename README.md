# Insertrix

A tetris clone, built with HTML5/JavaScript. Your objective is to eliminate the rows that are being created with the rests of new pieces that fall from the upper part of the board. Beware that a number of trash rows will be created at the same time you destroy rows!

## Build

This is plain JavaScript (not even minified), no building needed.

## Run

Just open `index.html` in any web browser.
